# Комірка 1.0

**Android 8.0 і новіші. Український інтерфейс. Працює без інтернету.**

Відкрийте `Komirka-1.0-debug.apk` на Android-телефоні та встановіть додаток. Якщо система попросить, дозвольте встановлення з вибраного файлового менеджера. Це готова збірка з тестовим підписом; вона не опублікована в Google Play.

1. **Створити таблицю** → назва, за потреби ID → **Далі: стовпці**.
2. Додайте свої поля. Для category / ordinal додайте категорії; ordinal можна впорядкувати стрілками.
3. **Новий запис** → заповніть поля → **Перевірити** → **Закінчити та додати до таблиці**.
4. Щоб зробити перерву, натисніть **Зберегти чернетку та вийти**. Дані ще не стануть записом; чернетка чекатиме у відповідній таблиці.
5. Натисніть на наявний запис для редагування. Історія / aliases дозволяє відновити, змінити або видалити старі значення.
6. **Експорт** зберігає CSV або JSON у вибраному вами місці. **Імпортувати CSV** на головному екрані створює нову таблицю, з якою можна працювати далі.

Пропущене значення — порожня клітинка CSV або `null` у JSON. JSON додатково містить типи, категорії та історію; імпорт підтримує CSV.

Видалення додатка чи очищення його даних видаляє локальні таблиці. Зберігайте важливі дані через експорт.

**Перевірено:** APK зібрано й перевірено підпис; 46 автоматичних тестів пройдено; Android Lint — 0 помилок (7 рекомендацій). Екрани відрендерено в тестовому Android runtime. На фізичному телефоні ще не тестувалося.

Вихідний код: `Komirka-source.zip`. Докладна інструкція та опис формату JSON: `README.md` у проєкті. Знімки нативних екранів: `screenshots/`. Детальні результати: `verification.json` і `reports/`.
